# Three projects-page variations

Every variation uses the same `/projects-yard` URL when its branch is checked out. Each retains a link from the main portfolio, concrete project capabilities, explicitly labeled concepts, and verified merged work in Antonio’s own repositories.

| Branch | Direction | Main interaction |
| --- | --- | --- |
| `codex/projects-systems-yard` | Ivory, graphite and copper industrial study | Explode a five-layer compute stack, select a software layer, inspect project examples. |
| `codex/projects-dispatch` | Dark chartreuse hardware network | Route packets, raise individual modules, open internal subrigs and unfold execution workspaces. |
| `codex/projects-deep-field` | Monumental high-desert observatory | Fly between six articulated project stations, reveal signal routes and operate the workshop crane. |

The first two designs remain committed on their own branches. This branch contains Deep Field. Each includes its own Blender source, exported models, generated artwork and provenance. Switch to a branch and run `npm run dev` to view that variation. The hosted preview follows the most recently deployed design; switching a local branch does not change the hosted site.
